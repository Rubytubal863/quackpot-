REM Title: Cursor Theme Swap (GNOME)
REM Description: saves the gnome cursor theme, swaps it for eight seconds, then restores the exact one.
REM Target OS: Linux (GNOME)
REM Novelty: a cursor swap that saves and restores the previous theme, not in the repo.
REM Revert: auto, the saved theme is restored after the sleep.
REM Author: azzie

ATTACKMODE HID
REM Let the HID keyboard interface enumerate before typing
DELAY 1200

REM Open the default terminal (GNOME and most desktops: Ctrl+Alt+T)
CTRL ALT t
REM Give the terminal window time to spawn and take focus
DELAY 1200

REM Stash current cursor theme in OLD, swap to Adwaita for 8s, then restore OLD verbatim
STRINGLN OLD=$(gsettings get org.gnome.desktop.interface cursor-theme); gsettings set org.gnome.desktop.interface cursor-theme 'Adwaita'; sleep 8; gsettings set org.gnome.desktop.interface cursor-theme "$OLD"
