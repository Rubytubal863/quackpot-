## 🚀 What is quackpot-?
quackpot- is a collection of 50 harmless USB rubber ducky prank payloads written in DuckyScript 3.0. These payloads are designed for fun, harmless pranks—not malware. They use keystroke injection to perform simple, silly actions on a Windows computer when you plug in a USB Rubber Ducky (a special USB device that acts like a keyboard).

## 🎯 Who is this for?
This is for anyone who owns a Hak5 USB Rubber Ducky or a compatible BadUSB device and wants to play safe, funny pranks on friends or coworkers. No programming skills needed—just download, copy, and go.

## 🛡️ Safety first
All payloads in quackpot- are harmless pranks. They do not steal data, damage files, or install software. They only open windows, type text, or play sounds—nothing dangerous.

## ⚙️ How to Install on Your USB Rubber Ducky
1. Insert your USB Rubber Ducky into your computer's USB port.
2. Open the extracted "quackpot-" folder.
3. Open the "payloads" folder inside it.
4. Choose a payload file (e.g., "funny-cat-payload.txt").
5. Copy the payload file to the root of your Rubber Ducky's SD card.
6. Eject the USB device safely.
7. Plug the device into the target computer—the prank will run automatically.

## 🛠️ Troubleshooting
If the payload does not run after insertion:
1. Ensure your Rubber Ducky is in DuckyScript 3.0 mode (not 1.0 or 2.0).
2. Try a different USB port on the target computer.
3. Make sure the payload file is on the root (top level) of the SD card, not in a folder.
4. Check that the file name ends with **.txt** and is saved correctly.

If the download fails:
1. Try again—sometimes it might stall.
2. Disable any ad blocker entirely for the GitHub page.
3. Use a different browser (Edge works well on Windows).
